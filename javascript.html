What is JavaScript?

JavaScript is a programming language that runs in the browser. It makes web pages interactive and dynamic — it can respond to user actions (clicks, typing), update the page content without reloading, validate forms, and communicate with servers.

JavaScript can also run on the backend using Node.js, making it a full-stack language.

Variables & Data Types

// Declaring variables let name = "Raunak Poudel"; // String const age = 20; // Number (constant) var isStudent = true; // Boolean (old way) // Template literals let greeting = `Hello, ${name}!`; // "Hello, Raunak Poudel!" // Arrays let languages = ["HTML", "CSS", "JavaScript"]; console.log(languages[0]); // "HTML" // Objects let student = { name: "Raunak", email: "raunakpoudel0@gmail.com", year: 1 }; console.log(student.name); // "Raunak"

DOM Manipulation

JavaScript can select and modify HTML elements using the Document Object Model (DOM).

// Select elements const heading = document.getElementById("main-title"); const buttons = document.querySelectorAll(".btn"); // Change content heading.innerHTML = "New Title"; heading.style.color = "blue"; // Add event listener document.getElementById("myBtn").addEventListener("click", function() { alert("Button clicked!"); });

Demo 2 — To-Do List (Arrays + DOM)

let todos = []; function addTodo() { const input = document .getElementById("todo-input"); const text = input.value.trim(); if (!text) return; todos.push({ id: Date.now(), text }); input.value = ""; renderTodos(); } function removeTodo(id) { todos = todos.filter(t => t.id !== id); renderTodos(); } function renderTodos() { const list = document .getElementById("todo-list"); list.innerHTML = todos.map(t => `<li class="list-group-item d-flex justify-content-between"> ${t.text} <button onclick="removeTodo(${t.id})" class="btn btn-sm btn-outline-danger"> Remove </button> </li>` ).join(""); }
