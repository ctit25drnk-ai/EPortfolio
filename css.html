CSS — Cascading Style Sheets

Section 03 — CET138 Assignment 1 — Raunak Poudel

What is CSS?

CSS (Cascading Style Sheets) is the language used to control the appearance of HTML documents. While HTML defines the structure, CSS defines how it looks — colours, fonts, spacing, and layout.

The word "cascading" refers to the order in which styles are applied. More specific rules override less specific ones (e.g. an ID selector overrides a class selector).

CSS Syntax

A CSS rule has a selector and a declaration block:

/* Selector { property: value; } */ h1 { color: blue; font-size: 2rem; } .card { background-color: #fff; padding: 1rem; border: 1px solid #ccc; border-radius: 6px; } #main-title { font-weight: bold; text-align: center; } /* Pseudo-class */ a:hover { color: red; text-decoration: underline; }

The Box Model

Every HTML element is treated as a rectangular box. The box model has four layers:

  • Content — the actual text or image inside
  • Padding — space between content and the border
  • Border — the outline of the element
  • Margin — space outside the border, separating elements
.box { margin: 20px; /* Outside spacing */ border: 2px solid black; padding: 15px; /* Inside spacing */ width: 200px; }

Flexbox

Flexbox is a CSS layout system that makes it easy to align and distribute items in a row or column.

.container { display: flex; justify-content: space-between; align-items: center; gap: 1rem; } .item { flex: 1; background: #0d6efd; color: white; padding: 1rem; text-align: center; border-radius: 4px; }

Responsive Design — Media Queries

Media queries allow different styles to be applied depending on the screen size. This is how websites are made responsive.

/* Default styles (mobile) */ .container { width: 100%; } /* Tablet and above */ @media (min-width: 768px) { .container { width: 750px; margin: 0 auto; } } /* Desktop */ @media (min-width: 1024px) { .container { width: 960px; } }

CSS Variables (Custom Properties)

CSS variables allow you to define reusable values that can be used throughout your stylesheet.

:root { --primary-color: #0d6efd; --font-size-base: 16px; --border-radius: 6px; } .button { background-color: var(--primary-color); font-size: var(--font-size-base); border-radius: var(--border-radius); }

Transitions & Animations

/* Smooth hover transition */ .btn { background: #0d6efd; transition: background 0.3s ease; } .btn:hover { background: #0a58ca; } /* Keyframe animation */ @keyframes fadeIn { from { opacity: 0; } to { opacity: 1; } } .box { animation: fadeIn 1s ease; }
